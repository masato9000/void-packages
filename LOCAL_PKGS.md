## Localpkgs branch
package templates for software of personal interest

### Packages in this branch:
- `black-box` - The logic game; this is the SDL-version from www.linux-games.com
- `ksh-openbsd` - Truly free (noGPL3) port of OpenBSD's PDKSH from Lévai Dániel

### Not maintaining (historic) or broken:
- `funguloids` - BROKEN - Those Funny Funguloids - Weird/Fun game built on libogre
- `xfce4-mount-plugin` - HISTORIC - somewhat recently maintained but missing from Void...
- `encryptpad` - BROKEN - Edit encrypted text (without writing unencrypted data to disk!)
- `xdman` - HISTORIC - Xtreme Download Manager - java-based download manager with browser monitoring
